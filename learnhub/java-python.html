Java + Python

Two languages taught side by side — from your first line of code to object-oriented programming, data structures, files, concurrency, testing and interview-level problem solving. No prior programming experience required.

1. What is programming? Meet Java and Python

A computer follows instructions. Programming means writing those instructions in a language a computer can run. A program can calculate marks, power a website, automate a task or control a device.

⌨️Code

What are Java and Python?

  • Java: a statically typed, class-based language. Source code is compiled to bytecode and commonly runs on the Java Virtual Machine (JVM). Used in backend services, enterprise systems, Android development and test automation.
  • Python: a dynamically typed, high-level language known for readable syntax. Common in automation, scripting, data science, AI, backend services and testing.
  • Both: general-purpose languages with variables, conditions, loops, functions/methods, data structures, OOP and exception handling.
FeatureJavaPython
TypingStatic: types are declared or inferred at compile timeDynamic: names can refer to values of different types

Important: neither language is universally “better” or automatically faster in every task. Choose based on the job, ecosystem, constraints and team. Learning one makes the other easier, but their syntax and runtime rules are not identical.

How a program becomes a result

  1. Write source code in an editor.
  2. Translate/execute it using the language toolchain.
  3. The runtime executes instructions and uses operating-system resources.
  4. Inspect output and errors, then debug and improve the program.

Setup checklist

  • Install a current supported JDK for Java; verify with java -version and javac -version.
  • Install Python 3; verify with python --version or python3 --version.
  • Use an editor or IDE, a terminal, and a folder for practice files.
  • Run one tiny program in each language before moving on.

2. Your first program and how to run it

Start by printing a message. Printing sends text to the terminal; it does not save the text into a variable.

Java — Hello.java

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}

Run: javac Hello.java, then java Hello.

Python — hello.py

print("Hello, world!")

Run: python hello.py or python3 hello.py.

Understand every part

  • Java class: code is organized in classes. A public class named Hello normally lives in Hello.java.
  • main method: the conventional entry point for a basic Java application. String[] args receives command-line arguments.
  • System.out.println: prints a line and then moves to the next line.
  • Python print(): a built-in function that displays values; Python does not need a class or main method for a tiny script.
  • Case sensitivity: age, Age and AGE are different names in both languages.

Comments

Java

// One-line comment
/* Multiple-line
   comment */

Python

# One-line comment
"""A triple-quoted string is often
used as a docstring when placed
at the start of a module/function."""

Errors you will meet

  • Syntax error: code breaks the language grammar, such as a missing Java semicolon or incorrect Python indentation.
  • Runtime error/exception: code starts but fails while running, such as dividing by zero.
  • Logic error: program runs but produces the wrong answer.

Input and output

Java

import java.util.Scanner;

Scanner sc = new Scanner(System.in);
System.out.print("Enter age: ");

Learn Scanner token input versus nextLine(); mixing them can leave a newline to consume.

Python

age = int(input("Enter age: "))
print(f"Age = {age}")

input() returns text, so convert it when a number is needed.

Operators

  • Arithmetic: + - * / %; Java also has integer division for integer operands, while Python / returns a float and // is floor division.
  • Comparison: == != < > <= >= returns a boolean result.
  • Logical: Java && || !; Python and or not.
  • Assignment: = += -= *= and similar compound operators.
  • Increment: Java has i++; Python does not. Use i += 1.
  • Equality: Java uses == for primitive values and reference identity; use .equals() for String content. Python uses == for value equality and is for identity.

4. Decisions, loops and control flow

Programs choose paths and repeat work. Indentation is meaningful in Python; Java groups blocks with braces.

Java — if / else

int score = 76;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 60) {
    System.out.println("Pass");
} else {
    System.out.println("Retry");
}

Python — if / elif / else

score = 76
if score >= 90:
    print("A")
elif score >= 60:
    print("Pass")
else:
    print("Retry")

Loops

Java

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
int n = 3;
while (n > 0) {
    System.out.println(n);
    n--;
}

Python

for i in range(5):
    print(i)
n = 3
while n > 0:
    print(n)
    n -= 1
  • For loop: useful when iterating a range or collection.
  • While loop: repeats while a condition remains true; ensure progress toward stopping.
  • break: exits the nearest loop.
  • continue: skips to the next iteration.
  • Nested loops: one loop inside another; often used for grids, pairs and matrix operations.
  • Off-by-one error: using the wrong boundary. Python range(5) produces 0 through 4; Java condition i < 5 does the same.

Switch / match and conditional expressions

Java switch (modern syntax)

String dayType = switch (day) {
    case "Sat", "Sun" -> "Weekend";
    default -> "Weekday";
};

Python match (3.10+)

match day:
    case "Sat" | "Sun":
        day_type = "Weekend"
    case _:
        day_type = "Weekday"

Use these when they improve clarity; a simple if is often enough. Java switch features depend on the JDK version.

5. Strings and text processing

A string represents text. Java strings and Python strings are immutable: operations usually create a new string rather than modifying the existing one.

Java

String name = "RAM";
System.out.println(name.length());
System.out.println(name.toLowerCase());
System.out.println(name.substring(0, 2));
System.out.println(name.contains("A"));
String joined = name + " learns Java";
String formatted = String.format("Score: %d", 90);

Python

name = "RAM"
print(len(name))
print(name.lower())
print(name[0:2])
print("A" in name)
joined = name + " learns Python"
formatted = f"Score: {90}"

Indexing and slicing

  • Indexes are usually zero-based: first character is index 0.
  • Java substring(start, end) uses an exclusive end index and does not support negative indexes.
  • Python slicing text[start:end:step] has an exclusive end; negative indexes count from the end.
  • Handle empty strings and boundaries before indexing to avoid exceptions.

String comparison and construction

  • Java: compare contents with text.equals(other); use StringBuilder for many repeated concatenations in a loop.
  • Python: use == for value equality and "".join(parts) for joining many pieces efficiently.
  • For user input, consider whitespace with trim() in Java and strip() in Python.
  • Unicode text can contain multi-code-point graphemes; a visible character is not always one code unit or one code point.

Operations to master

  • Read/update by index, append/add, insert, remove, delete, membership test, length and iteration.
  • Lists/ArrayLists allow duplicates; sets remove duplicates; maps/dictionaries associate keys with values.

7. Functions and methods

A function/method packages a task into a reusable unit. Parameters are inputs; a return value sends a result back to the caller.

Java method

static int add(int a, int b) {
    return a + b;
}
// call:
int result = add(3, 4);

Python function

def add(a, b):
    return a + b

result = add(3, 4)

Parameters, return, scope

  • Parameter: variable declared in the function definition. Argument: value supplied during a call.
  • return: ends the function and optionally gives back a value. Printing a value is not the same as returning it.
  • Scope: determines where a name can be accessed. Prefer local variables and explicit inputs/outputs over hidden global state.
  • Overloading: Java supports methods with the same name and different parameter lists. Python normally uses one function definition; defaults or argument handling are common alternatives.
  • Recursion: a function calls itself. It needs a base case and progress toward that case, otherwise it may overflow the call stack or hit recursion limits.

Defaults, named arguments and varargs

Java

static int sum(int... values) {
    int total = 0;
    for (int v : values) total += v;
    return total;
}
// sum(1, 2, 3)

Python

def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"

def total(*values):
    return sum(values)

greet(name="RAM", greeting="Hi")

Python also supports **kwargs for collecting keyword arguments. Avoid mutable defaults such as def f(items=[]); the same list would be reused across calls.

Lambda functions

Java lambda

names.sort((a, b) -> a.length() - b.length());

Python lambda

names.sort(key=lambda name: len(name))

Use lambdas for small expressions. For complex logic, define a named function. In Java, lambdas commonly implement functional interfaces.

8. Object-oriented programming (OOP)

OOP organizes code around objects that combine state and behavior. A class is a blueprint; an object is an instance created from it.

Java class

class Student {
    private String name;
    private int marks;

    Student(String name, int marks) {
        this.name = name;
        this.marks = marks;
    }
    public String getName() { return name; }
    public boolean passed() { return marks >= 40; }
}
Student s = new Student("RAM", 82);

Python class

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def passed(self):
        return self.marks >= 40

s = Student("RAM", 82)

The four common OOP principles

  • Encapsulation: keep state and related behavior together; protect invariants. Java uses access modifiers such as private and public methods. Python conventionally uses leading underscores; it does not enforce privacy the same way.
  • Abstraction: expose what a caller needs and hide implementation details. Java has interfaces and abstract classes; Python has abstract base classes in abc.
  • Inheritance: a class derives behavior from a parent. Use it for a genuine “is-a” relationship, not just to reuse a few lines.
  • Polymorphism: the same interface can lead to different behavior depending on the actual object. Python often relies on duck typing; Java commonly uses interface or superclass references.

Inheritance and overriding

Java

interface Payable {
    double amount();
}
class Invoice implements Payable {
    public double amount() { return 125.0; }
}
Payable p = new Invoice();
System.out.println(p.amount());

Python

class Payable:
    def amount(self):
        raise NotImplementedError

class Invoice(Payable):
    def amount(self):
        return 125.0

p = Invoice()
print(p.amount())

OOP concepts beyond the basics

  • Constructor: initializes a new object. Java constructor name matches the class; Python uses __init__ to initialize an already-created instance.
  • this / self: Java this refers to the current object; Python methods explicitly receive the instance conventionally named self.
  • Static/class members: Java static members belong to the class. Python has class attributes and @classmethod; instance attributes are usually set on self.
  • Composition: one object contains or uses another (“has-a”). Often more flexible than inheritance.
  • Overloading vs overriding: overloading selects among signatures (Java); overriding replaces inherited behavior. Python overriding is common, but traditional signature-based method overloading is not built in.
  • Special methods: Python __str__, __repr__, __len__, and operator methods customize object behavior.
  • Equality: define equality consistently. In Java, overriding equals normally requires a matching hashCode. Python may implement __eq__.

9. Exceptions and defensive programming

An exception signals that normal execution cannot continue as written. Handle exceptions you can meaningfully recover from; do not hide every error with a blanket catch.

Java

try {
    int value = Integer.parseInt("42");
    System.out.println(value);
} catch (NumberFormatException e) {
    System.out.println("Invalid number");
} finally {
    System.out.println("Cleanup runs");
}

Python

try:
    value = int("42")
    print(value)
except ValueError:
    print("Invalid number")
finally:
    print("Cleanup runs")

Java vs Python exception model

  • Java has checked exceptions (must be caught or declared in many contexts) and unchecked exceptions (subclasses of RuntimeException, among others).
  • Python exceptions are unchecked; the code documents and handles expected failures at runtime.
  • Java uses throw to raise and throws to declare; Python uses raise.
  • Use Java try-with-resources or Python with for reliable resource cleanup.
  • Catch specific exception types, add context, and preserve the original cause when re-raising.

Custom exceptions

Java

class InvalidAgeException extends Exception {
    InvalidAgeException(String message) {
        super(message);
    }
}

Python

class InvalidAgeError(Exception):
    pass

if age < 0:
    raise InvalidAgeError("Age cannot be negative")

Validate external input at boundaries, but avoid redundant checks everywhere. Errors should be understandable to users and detailed enough in logs for developers without leaking secrets.

10. Files, serialization and paths

Programs often read configuration, write reports and exchange structured data. Always consider encoding, file paths, permissions and cleanup.

Java — text file

import java.nio.file.*;
import java.io.IOException;

try {
    Files.writeString(Path.of("notes.txt"), "LearnHub\n");
    String text = Files.readString(Path.of("notes.txt"));
    System.out.println(text);
} catch (IOException e) {
    System.err.println("File operation failed: " + e.getMessage());
}

Python — text file

from pathlib import Path

path = Path("notes.txt")
path.write_text("LearnHub\n", encoding="utf-8")
text = path.read_text(encoding="utf-8")
print(text)

File handling checklist

  • Prefer explicit UTF-8 encoding for text files where practical.
  • Use paths rather than hard-coded platform-specific separators. Java Path and Python pathlib.Path help.
  • Use Java try-with-resources for streams/readers/writers; Python with open(...) closes the file reliably.
  • Distinguish text from binary files. Images, archives and many documents must be read/written in binary mode.
  • Handle missing files and permission errors appropriately.

JSON serialization

// With a JSON library such as Jackson:

11. Packages, modules, libraries and environments

Small programs grow into projects. Organize code into modules, isolate dependencies and make setup repeatable.

Java package

package com.learnhub.math;

public class Calculator {
    public int multiply(int a, int b) {
        return a * b;
    }
}

Packages group types; imports let source files refer to types by simple names.

Python module

# calculator.py
def multiply(a, b):
    return a * b

# in another file:
from calculator import multiply
print(multiply(3, 4))

A folder with Python modules can be organized as a package.

Dependency management

  • Java: learn Maven or Gradle; Maven commonly uses pom.xml to declare dependencies, build settings and tests.
  • Python: learn venv and pip; isolate project dependencies rather than installing everything globally. Modern projects may use pyproject.toml.
  • Reproducibility: document language/runtime versions and dependency versions, and keep secrets out of source control.
  • Entry point: Java uses a main method for standard applications; Python often uses if __name__ == "__main__":.

Python script guard

def main():
    print("Run as a script")

if __name__ == "__main__":
    main()

12. Generics, type hints and reusable design

Reusable code should work with multiple types without throwing away safety or clarity.

Java generics

static  T first(List values) {
    if (values.isEmpty()) {
        throw new IllegalArgumentException("Empty list");
    }
    return values.get(0);
}
List names = List.of("RAM", "Asha");
String firstName = first(names);

Python type hints

def first[T](values: list[T]) -> T:
    if not values:
        raise ValueError("Empty list")
    return values[0]

# Generic syntax depends on Python version;
# older versions use TypeVar from typing.

Java generics are checked by the compiler with type erasure in the usual implementation. Python type hints help editors and static analysis tools, but Python does not enforce them automatically at runtime. The newer Python generic syntax shown requires Python 3.12+; for older versions use TypeVar.

Design principles

  • Single responsibility: one class/function should have one clear reason to change.
  • Separation of concerns: keep input/output, business rules and storage separate.
  • Composition over inheritance: prefer assembling collaborators unless inheritance models a real subtype relationship.
  • DRY: avoid harmful duplication, but do not create abstractions for every two repeated lines.
  • Readable names: explain intent. Avoid unexplained abbreviations and huge methods.
  • API contracts: document valid inputs, output, side effects and possible failures.

13. Algorithms and Big-O analysis

An algorithm is a finite sequence of steps that solves a problem. Data structures and algorithmic complexity matter in both languages and in interviews.

Big-O intuition

ComplexityMeaning (roughly)Example
O(1)Constant workArray access by index
O(log n)Problem shrinks by a factor each stepBinary search in sorted data
O(n)Work grows with input sizeLinear scan
O(n log n)Common efficient comparison sortingMerge sort / typical efficient sorts
O(n²)Every item compared with many othersNested loop over all pairs
O(2ⁿ)Explosive growthNaive subset recursion

Linear search vs binary search

Java

static int binarySearch(int[] a, int target) {
    int left = 0, right = a.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

Python

def binary_search(a, target):
    left, right = 0, len(a) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

Precondition: the input must be sorted. Binary search runs in O(log n) time and uses O(1) extra space in this iterative form.

Core DSA roadmap

  1. Arrays and strings: traversal, prefix sums, two pointers, sliding window.
  2. Hashing: frequency counts, duplicate detection, pair sum.
  3. Linked lists: insert/delete, reverse, slow/fast pointers, cycle detection.
  4. Stacks and queues: balanced brackets, next greater element, BFS.
  5. Recursion and backtracking: subsets, permutations, maze paths.
  6. Sorting and binary search: custom comparators, bounds, search on answer.
  7. Trees and BSTs: traversals, height, validation, lowest common ancestor.
  8. Heaps: top K elements, merge sorted sequences.
  9. Graphs: adjacency lists, BFS/DFS, shortest paths, cycle detection, topological sort.
  10. Dynamic programming: define state, transition, base case, order and complexity.
Interview habit: explain a brute-force solution first, improve it, state time and space complexity, test edge cases, then write clean code. Memorizing a solution without understanding its invariant fails when the question changes.

Java collection framework

  • Set: unique elements; HashSet, LinkedHashSet, TreeSet have different order/performance properties.

  • heapq provides a min-heap; bisect helps binary-search sorted sequences.
  • Use a generator when you want to produce values lazily rather than build a full list.

15. Functional-style programming and iteration

Functional techniques emphasize transforming values, composing small operations and limiting side effects. Use them when they make code easier to reason about.

Java streams

List result = names.stream()
    .filter(name -> name.length() >= 4)
    .map(String::toUpperCase)
    .sorted()
    .toList();

Python map/filter/generator

result = sorted(
    name.upper()
    for name in names
    if len(name) >= 4
)

def squares(limit):
    for n in range(limit):
        yield n * n
  • Pure function: same inputs produce the same output and no externally visible side effect.
  • Map: transform each item. Filter: keep items that pass a condition. Reduce: combine values into one result.
  • Java stream: operations are often lazy until a terminal operation; streams should generally not be reused after a terminal operation.
  • Python generator: yields values one at a time, saving memory for large sequences; it is usually consumed as it iterates.
  • Immutability: reduces accidental state changes, but do not confuse an immutable reference with a deeply immutable object graph.

16. Threads, concurrency, parallelism and async

Concurrency means multiple tasks make progress during overlapping periods. Parallelism means work literally executes at the same time on multiple processing units. They are related but not the same.

I/O-bound tasksThreads or asynchronous APIsThreads or asyncio

Race conditions and synchronization

If two tasks read the same value and update it without coordination, one update can overwrite the other. This is a race condition. A critical section protects shared mutable state.

Java synchronized

class Counter {
    private int value = 0;
    public synchronized void increment() {
        value++;
    }
    public synchronized int get() {
        return value;
    }
}

Python lock

from threading import Lock

class Counter:
    def __init__(self):
        self.value = 0
        self.lock = Lock()

    def increment(self):
        with self.lock:
            self.value += 1

Deadlocks and safe design

  • A deadlock can occur when tasks wait forever for resources held by one another.
  • Reduce risk with a consistent lock ordering, small critical sections, timeouts where appropriate and avoiding nested locks where possible.
  • Prefer thread-safe queues and high-level concurrency abstractions instead of manually coordinating many low-level locks.
  • Java: learn ExecutorService, Future, CompletableFuture, concurrent collections and atomic variables.
  • Python: learn concurrent.futures, queue.Queue, multiprocessing and asyncio.

Python async/await

import asyncio

async def fetch_example():
    await asyncio.sleep(1)  # yields control; doesn't block the event loop
    return "done"

async def main():
    result = await fetch_example()
    print(result)

asyncio.run(main())

asyncio is particularly useful for many concurrent I/O operations when the libraries involved support async. It does not automatically make CPU-heavy code faster.

17. Memory management, references and garbage collection

Programs allocate objects, hold references to them and eventually release memory. Understanding references helps explain leaks, surprising mutation and performance problems.

  • Stack frames: hold call-related state such as local variables and return information conceptually; actual implementation details vary.
  • Heap: commonly stores dynamically allocated objects.
  • Java: automatic garbage collection reclaims unreachable objects. A memory leak can still occur when references unintentionally keep objects reachable.
  • Python: memory management is implementation-dependent. CPython commonly uses reference counting plus cyclic garbage collection.
  • Pass-by-value: Java passes values; when passing an object, the copied value is a reference. Python passes object references by assignment (often described as call-by-sharing).
  • Mutable vs immutable: mutating a shared list can be visible through multiple references; reassigning a local name does not reassign the caller's variable.

Java reference example

List a = new ArrayList<>();
List b = a;
b.add("hello");
// a also sees "hello": same list object

Python reference example

a = []
b = a
b.append("hello")
# a also sees "hello": same list object

Practical memory hygiene

  • Close streams, sockets and database connections; garbage collection is not a substitute for resource management.
  • Avoid retaining large caches or event listeners indefinitely.
  • Use profilers and heap/memory tools to measure before optimizing.
  • Do not assume a variable name directly “contains” a complex object; reference semantics matter.
INTERMEDIATE

18. Testing, debugging and code quality

Tests provide evidence that code behaves as expected. A useful test suite covers normal behavior, edge cases and failures.

Unit test example

Java — JUnit 5 style

import static org.junit.jupiter.api.Assertions.*;
import org.junit.jupiter.api.Test;

class CalculatorTest {
    @Test
    void addsTwoNumbers() {
        assertEquals(7, Calculator.add(3, 4));
    }
}

JUnit must be added as a project dependency.

Python — unittest

import unittest

def add(a, b):
    return a + b

class TestCalculator(unittest.TestCase):
    def test_add(self):
        self.assertEqual(add(3, 4), 7)

if __name__ == "__main__":
    unittest.main()

Test levels and practices

  • Unit test: small unit in isolation.
  • Integration test: verifies components work together, such as code and a database/API.
  • End-to-end test: checks a complete user workflow across the system.
  • Boundary cases: empty input, one item, minimum/maximum values, duplicates, invalid values and very large input.
  • Arrange–Act–Assert: prepare state, perform the action, verify the result.
  • Debugging: reproduce, reduce the problem, inspect state, form a hypothesis, test it, then add a regression test.
  • Quality tools: formatters, linters, static analysis, code review, CI and coverage reports.

Automation/testing ecosystem

  • Java: JUnit/TestNG, Maven/Gradle, Selenium WebDriver and REST Assured are common in test automation.
  • Python: pytest, unittest, Selenium, requests and API-testing libraries are commonly used.
  • Test design matters more than framework syntax: clear assertions, deterministic tests, isolated test data and actionable failure messages.
INTERMEDIATE

19. Working with APIs, databases and the operating system

Real applications connect to services and databases, read environment settings, and handle failures. Keep network and storage concerns outside core business logic where possible.

HTTP request example

Java (HttpClient)

HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://example.com"))
    .GET().build();
HttpResponse response = client.send(
    request, HttpResponse.BodyHandlers.ofString());
System.out.println(response.statusCode());

Requires imports from java.net.http; handle IOException and InterruptedException.

Python (standard library)

from urllib.request import urlopen

with urlopen("https://example.com") as response:
    print(response.status)
    body = response.read().decode("utf-8")

For richer HTTP work, projects often use a maintained HTTP library such as Requests.

Database access principles

  • Use parameterized queries or prepared statements; never build SQL by concatenating untrusted input.
  • Understand transactions, commit/rollback, connection pools and resource cleanup.
  • Keep credentials in environment/configuration or a secrets manager, not source code.
  • Expect timeouts, unavailable services, invalid responses and partial failures.
  • Use least-privilege database accounts and avoid logging passwords, tokens or sensitive records.

Command-line arguments and environment variables

Java

public static void main(String[] args) {
    String mode = args.length > 0 ? args[0] : "dev";
    String url = System.getenv("API_URL");
    System.out.println(mode);
}

Python

import os
import sys

mode = sys.argv[1] if len(sys.argv) > 1 else "dev"
url = os.getenv("API_URL")
print(mode)

20. Advanced language features and common pitfalls

Java topics to learn deeply

  • JVM architecture: class loading, bytecode, runtime data areas, execution engine and garbage collection.
  • Access modifiers: public, protected, package-private and private.
  • Interfaces and abstract classes: contracts, default methods, partial implementation and design trade-offs.
  • Generics: bounded types, wildcards (? extends/? super), type erasure and PECS.
  • Exceptions: checked vs unchecked, exception chaining and try-with-resources.
  • Collections: hashing, equality contracts, fail-fast iterators, concurrent collections and ordering guarantees.
  • Functional Java: functional interfaces, lambdas, method references, streams and Optional.
  • Concurrency: happens-before, visibility, atomicity, locks, executors, futures and virtual threads where supported by the chosen JDK.
  • Modern Java: records, enums, sealed classes, pattern matching and switch expressions; confirm the project's target JDK.
  • Build/runtime: classpath/module path, JARs, Maven/Gradle, JVM flags, profiling and diagnosing memory/latency.

Python topics to learn deeply

  • Object model: names, references, identity, mutability and equality.
  • Comprehensions and generators: lazy iteration, generator expressions and yield.
  • Decorators: wrap functions/classes to add behavior while preserving metadata where appropriate.
  • Context managers: with, __enter__/__exit__ and resource safety.
  • Iterators: __iter__, __next__ and the iterator protocol.
  • Descriptors and properties: control attribute access and validation.
  • Data classes: reduce boilerplate for data-focused classes using @dataclass.
  • Type system tools: annotations, Protocols, generics and static checkers; annotations are not automatic runtime validation.
  • Concurrency: threading, multiprocessing, futures, async event loops and the GIL implications for the Python implementation/version.
  • Packaging: virtual environments, package metadata, wheels, dependency locking and module import behavior.

Common bugs to avoid

  • Comparing Java strings with == rather than content equality.
  • Assuming Python assignment copies a list or dictionary; use an explicit copy when needed.
  • Mutating a collection while iterating over it in an unsupported way.
  • Using floating-point numbers for exact money calculations without a suitable decimal strategy.
  • Ignoring null/None, empty inputs, time zones, Unicode and integer/overflow assumptions.
  • Swallowing exceptions or catching overly broad errors without logging context.
  • Sharing mutable state across threads without a concurrency strategy.
  • Premature optimization before measuring a real bottleneck.

Reading is not enough. Build each project in both languages where practical; compare how the language changes the design, not only the syntax.

Beginner projects

  2. Marks manager: list/map data structures, average, highest/lowest marks and formatted output.

  3. REST API client: HTTP, JSON, status codes, timeouts and error handling.

Advanced projects

22. Practice problems with answers

Problem 1 — even or odd

Given an integer, print whether it is even or odd. Key idea: the remainder after division by 2.

Java

System.out.println(n % 2 == 0 ? "Even" : "Odd");

Python

print("Even" if n % 2 == 0 else "Odd")

Problem 2 — count frequencies

Count how often each item occurs. Expected average time is O(n) using a hash map/dictionary.

Java idea

Map freq = new HashMap<>();
for (int n : nums) {
    freq.put(n, freq.getOrDefault(n, 0) + 1);
}

Python idea

from collections import Counter
freq = Counter(nums)

Problem 3 — palindrome check

Decide whether text reads the same forward and backward. Clarify whether spaces, punctuation and letter case should be ignored.

Java (simple exact check)

boolean palindrome = text.equals(
    new StringBuilder(text).reverse().toString());

Python (simple exact check)

palindrome = text == text[::-1]

Problem 4 — remove duplicates while preserving order

Java

List unique = new ArrayList<>(
    new LinkedHashSet<>(nums));

Python

unique = list(dict.fromkeys(nums))

Problem 5 — find the second-largest distinct number

Do not sort by default; a one-pass solution is O(n). Define what happens if fewer than two distinct values exist.

Java

Integer largest = null, second = null;
for (int n : nums) {
    if (largest == null || n > largest) {
        if (largest == null || n != largest) second = largest;
        largest = n;
    } else if (n != largest &&
               (second == null || n > second)) {
        second = n;
    }
}
// second == null means no second distinct value

Python

distinct = set(nums)
if len(distinct) < 2:
    second = None
else:
    largest = max(distinct)
    second = max(n for n in distinct if n != largest)

Problem 6 — validate parentheses

Use a stack. Push opening brackets; on a closing bracket, verify the top matches. The algorithm is O(n) time.

Java outline

Deque stack = new ArrayDeque<>();
Map pairs = Map.of(
    ')', '(', ']', '[', '}', '{');
for (char ch : text.toCharArray()) {
    if (ch == '(' || ch == '[' || ch == '{') stack.push(ch);
    else if (pairs.containsKey(ch)) {
        if (stack.isEmpty() || stack.pop() != pairs.get(ch))
            return false;
    }
}
return stack.isEmpty();

Python outline

stack = []
pairs = {')': '(', ']': '[', '}': '{'}
for ch in text:
    if ch in '([{':
        stack.append(ch)
    elif ch in pairs:
        if not stack or stack.pop() != pairs[ch]:
            return False
return not stack

Problem 7 — binary search

Use the implementation in the Algorithms section. Test target at first/last index, absent target, empty input and duplicates (decide whether any, first or last match is needed).

Interactive self-check

Question: What is the output of Python print(7 / 2, 7 // 2)?

3.5 3 — / performs true division; // performs floor division.

Question: In Java, what is the safer way to compare String contents?

Use a.equals(b) (with a null-safe approach if either value may be null). == compares reference identity for objects.

Question: Why is binary search not valid on an arbitrary unsorted array?

It decides which half to discard based on ordering. Without sorted order, that decision can discard the target.

23. Short notes — Java + Python

Programming fundamentals

  • Variable: a name referring to a value; Java declares a type, Python binds names dynamically.
  • Condition: chooses a path; loops repeat; functions package reusable logic.
  • Array/list: indexed sequence; array size is fixed in Java, Python list is resizable.
  • Set: unique values. Map/dict: key-value lookup. Stack: LIFO. Queue: FIFO.
  • String: immutable text in both languages; Java content comparison uses equals.
  • Exception: runtime signal for failure; catch only what you can handle meaningfully.

OOP quick notes

  • Class: blueprint; object: instance.
  • Encapsulation: protect state and invariants. Abstraction: expose a simple contract.
  • Inheritance: reuse/extend a subtype relationship. Polymorphism: same contract, different behavior.
  • Composition: build an object using collaborators; often more flexible than inheritance.
  • Java: interfaces, access modifiers, static members, generics, JVM. Python: duck typing, conventions for privacy, decorators, generators.

DSA quick notes

  • O(1) constant; O(log n) logarithmic; O(n) linear; O(n log n) efficient comparison sorting; O(n²) quadratic.
  • Binary search requires sorted input and takes O(log n) time.
  • Hash map/set lookup is average O(1); do not confuse average with guaranteed worst case.
  • Stack: balanced brackets/DFS. Queue: BFS. Heap: top K. Graph: BFS/DFS. DP: state + transition + base case.
  • Always state complexity and test edge cases.

Runtime, testing and production

  • Java source compiles to bytecode executed by the JVM; Python is commonly executed by an interpreter implementation.
  • Garbage collection does not remove the need to close files, sockets or database connections.
  • Unit tests target small units; integration tests verify components together; end-to-end tests verify full workflows.
  • Use Git, code review, automated tests, dependency management, logging and CI.
  • Never commit secrets. Validate external input and use parameterized database queries.

24. Important interview questions with short answers

Core programming

  1. What is the difference between compiler and interpreter? A compiler translates code ahead of execution; an interpreter/runtime executes code through its implementation. Real language toolchains can combine compilation and interpretation.
  2. What is static vs dynamic typing? Static typing checks declared/inferred types before execution; dynamic typing associates types with runtime values and checks operations at runtime.
  3. What is the difference between syntax and logic errors? Syntax violates language grammar; logic error produces incorrect behavior despite running.
  4. What is pass-by-value in Java? Java always passes argument values; for objects, the value copied is a reference, so the method can mutate the referenced object but cannot reassign the caller's variable.
  5. How are arguments passed in Python? Names are bound to passed objects (call-by-sharing); mutation of a shared mutable object may be visible to the caller.
  6. Why are strings immutable? Immutability supports safe sharing and predictable behavior; implementation benefits include caching and optimization, though exact internals vary.

OOP

  1. Overloading vs overriding? Overloading uses different parameter signatures; overriding supplies a subtype's implementation of inherited behavior.
  2. Interface vs abstract class in Java? Interfaces define contracts and can support multiple implementation; abstract classes can hold shared state and partial implementation.
  3. Does Python support multiple inheritance? Yes; method resolution order (MRO) determines lookup order. Design it carefully.
  4. Encapsulation vs abstraction? Encapsulation bundles/protects state and behavior; abstraction exposes essential operations while hiding details.
  5. Composition vs inheritance? Composition builds behavior from collaborators; inheritance models a subtype. Prefer the relationship that fits the domain.
  6. What is polymorphism? Different object types can be used through a shared contract while dispatching to their own behavior.

Collections and DSA

  1. Array vs ArrayList in Java? Arrays have fixed length and can hold primitives; ArrayList resizes and stores reference types through generics/autoboxing.
  2. List vs tuple in Python? Lists are mutable; tuples are immutable containers.
  3. HashMap vs TreeMap? HashMap is hash-based with average constant-time basic operations; TreeMap maintains sorted key order with logarithmic operations.
  4. How does a hash map work? It hashes a key to locate a bucket and resolves collisions; correct equality/hash contracts are essential.
  5. When would you use a stack or queue? Stack for LIFO tasks like DFS/bracket validation; queue for FIFO tasks like BFS and task processing.
  6. What is Big-O? A way to describe how time/space requirements scale as input grows, ignoring constant factors at a high level.
  7. Why is binary search O(log n)? Each step roughly halves the remaining search interval.
  8. How do you find duplicates efficiently? Usually scan once with a set/map for average O(n) time and O(n) additional space.

Java-specific

  1. What is the JVM? The runtime that loads and executes Java bytecode and provides services such as memory management.
  2. JDK vs JRE vs JVM? JVM executes bytecode; runtime libraries/runtime components support execution; JDK adds developer tools such as the compiler. Packaging terminology varies across JDK distributions.
  3. Why use equals() and hashCode() together? Equal objects must have equal hash codes so hash-based collections can locate them correctly.
  4. Checked vs unchecked exception? Checked exceptions are subject to compile-time catch/declare rules; unchecked exceptions are not required to be declared.
  5. What is a lambda? A concise implementation of a functional interface's behavior, often used with streams and callbacks.
  6. What is garbage collection? Automatic reclamation of memory for objects no longer reachable, according to the runtime's collector.
  7. What is synchronization? A way to coordinate access to shared state and establish memory visibility/ordering guarantees.

Python-specific

  1. List vs generator? A list stores materialized items; a generator yields items lazily as requested.
  2. What is a decorator? A callable that takes a function/class and returns a wrapped or modified callable/class.
  3. What is a context manager? A construct used with with to reliably set up and clean up resources.
  4. What is the GIL? In common CPython builds, the Global Interpreter Lock limits simultaneous execution of Python bytecode in threads; behavior and free-threaded options depend on Python version/build.
  5. What is a virtual environment? An isolated Python environment for project dependencies.
  6. What is duck typing? Code relies on an object's supported behavior rather than requiring a specific declared class.
  7. What is a comprehension? A concise way to construct a collection from an iterable with optional filtering.

Testing and practical engineering

  1. Unit vs integration test? Unit tests isolate a small component; integration tests verify multiple components together.
  2. What makes a good test? Deterministic, isolated, readable, focused, with meaningful assertions and clear failure messages.
  3. How do you debug a production issue? Establish impact, inspect safe logs/metrics/traces, reproduce, isolate the cause, mitigate, fix and add a regression test.
  4. Why use Git? Version history, collaboration, branching, review and recovery.
  5. How do you protect secrets? Use environment/configuration or a secrets manager, least privilege, rotation and redaction; never commit them.
  6. How would you choose Java or Python? Based on role requirements, ecosystem, runtime/performance needs, team skills and maintainability—not a universal language ranking.
Interview method: answer the definition, explain the mechanism, give a small example, mention a trade-off and state complexity where relevant. If you do not know something, say what you know and reason from fundamentals instead of bluffing.
